# Build Agent Assistant with watsonx

In this lab you will build an **agentic Sales Assistant** powered by watsonx.  
You will create **two specialized agents** that work together:
1. **Customer Agent** – focuses on customer profiling & segmentation  
2. **Product Agent** – focuses on understanding & explaining investment products

Later labs will combine these with additional agents (sales enablement, performance, etc.)<br>

---

By the end of this lab you will be able to:<br>
- Define an **agent profile & behavior** prompt in watsonx  
- Attach tools to an agent using an **OpenAPI specification**  
- Test your agent with simple **Q&A prompts** using real sample data
