# Customer agent
This agent is used to do profiling and segmenting the customer where we would like to understanding from raw features into customer personas
Role: Customer understanding specialist

**Inputs:** Data dummy that are generated on [HERE](https://github.com/Client-Engineering-Indonesia/Workshop-AI-Sales-Assistant/blob/main/assets/data/customer_data.csv)

**Actions:** Rule-based labels (income bands, risk appetite, life stage, channel preference)

**Outputs:** Descriptions for each customer "segment cards" that later will be used for chatbot / sales reps

Performance Optimization Agent

Role: Continuous improvement coach
Goal: Make the whole system smarter over time.

Inputs
- Logs: offers shown vs accepted, conversion rates, churn, complaints
- Agent feedback: why a rep overrode a recommendation, manual notes

Actions
- Analyze patterns (which segments convert on which products, which scripts work)
- Detect under-performing rules & bias
- Propose changes: new segments, new product bundles, different pitch wording

Outputs
- Dashboards & alerts for managers
- Updated configuration / parameters for other agents (e.g., new weights in recommender)
