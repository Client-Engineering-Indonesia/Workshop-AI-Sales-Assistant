# Enterprise custom tools

watsonx orchestrate can connect to your own systems using OpenAPI tools. This lets the agent do real actions such as sending emails, creating calendar meetings, or calling your internal APIs.

After you connect a tool, watsonx can understand it and use it automatically during a conversation. This makes the agent more useful because it can work directly with your enterprise systems and automate tasks
