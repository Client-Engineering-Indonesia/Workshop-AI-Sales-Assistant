# Embed ChatBot watsonx orchestrate

You can embed an IBM watsonx Orchestrate chat widget on top of your existing interface using the Orchestrate web-embed script. This allows you to add the chat experience to any front-end design without modifying your current website code.

---

Go back to your watsonx orchestrate and choose which AgentID that you want to deploy<br>
