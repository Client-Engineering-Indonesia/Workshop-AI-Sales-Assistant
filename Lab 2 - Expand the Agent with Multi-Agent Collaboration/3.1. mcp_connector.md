# MCP connector using Tavily connector 

The Model Context Protocol (MCP) is a standard that allows agents to safely and easily connect to external tools and data through MCP servers. These servers act like a bridge, giving agents ready-to-use tools (web search, database queries, email, content fetching, etc.) without needing custom APIs or manual setup.

With MCP, agents can discover and use tools on the fly, expanding what they can do. Because everything follows one unified protocol, the process becomes simpler and more efficient. MCP also lets agents from different platforms share the same tools.

In this lab, you will learn how to add a Tavily Web Search tool to an agent using the Tavily MCP server. If you want to explore MCP in Langflow, click [HERE](https://github.com/Client-Engineering-Indonesia/Incubation-Agentic-AI-2025-batch-2/tree/main/Lab%201%20-%20Build%20RAG%20tools%20using%20Langflow%20and%20watsonx%20Discovery).

Tavily is a search engine built for AI agents and RAG. It gives real-time, accurate, and concise results that LLMs can use directly—making it simple to bring fresh web information into AI applications.
