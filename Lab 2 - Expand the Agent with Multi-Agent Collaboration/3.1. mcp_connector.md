# MCP connector using Tavily connector 

The Model Context Protocol (MCP) is a standard that lets agents easily and securely connect to external tools and data sources through MCP servers. These servers act as a bridge, providing ready-made tools—like web search, database queries, sending emails, or fetching content—without the need to build custom APIs or manual integrations.

With MCP, agents can discover and use external tools at runtime, expanding their abilities beyond what they were originally designed to do. All tool interactions follow one unified protocol, making the process simpler, more efficient, and easier to manage.

MCP also makes it possible for agents from different platforms or vendors to share and use the same tools, enabling better collaboration and interoperability. During this lab you will learn how to add a Tavily web search tool to an agent, imported using an MCP server provided by Tavily. If you want to try MCP server with Langflow [HERE](https://github.com/Client-Engineering-Indonesia/Incubation-Agentic-AI-2025-batch-2/tree/main/Lab%201%20-%20Build%20RAG%20tools%20using%20Langflow%20and%20watsonx%20Discovery).

Tavily is a search engine and API made specifically for AI agents and RAG (Retrieval-Augmented Generation). It provides real-time, accurate, and factual results that are easy for large language models (LLMs) to use. Unlike normal search engines, Tavily gives concise, LLM-friendly answers, making it easier to add fresh web information into AI applications.

### Step 2. Import MCP connector in watsonx orchestrate 



To install MCP servers that require environment variables, you must add the required variables into an AppID/Connection using key-value pairs. MCP servers fetch the environment variables when they start, so it is important to set the variables before you import or start an MCP server.

To connect to the Tavily server with your credentials, you must create a new connection in watsonx orchestrate. This is the most secured way to import tools not displaying your API keys and credentials publicly.

Return to your watsonx Orchestrate top menu. 
1. Click the Main menu icon (A)
2. Expand the Manage menu (A) then select Connections (B)
3. Click Add new connection (A).
4. Enter Tavily_MCP in the Connection ID* field (A), click Save and continue (B).
5. Expand the Choose an option in the  Authentication type menu (A). 
6. Select Key Value Pair (A).
7. Type TAVILY_API_KEY in the Key name field (A),  copy your Tavily API key from your note in the 
Value field (B), Click Connect (C).
8. Check that your draft connection is Connected (A), Click Next (B).
9. Repeat from Step 5 and add the credentials for the Live environment. 
10. Click Add connection (A) when done.
11. Check that your  connection is now ready (A), both draft and live environments will have access to 
your credentials in a secured way. Click the top menu (B).

---

Profile
Description
You are an agent that analyzes customer information to (1) profile and segment customers based on their financial behavior and needs, and (2) match them with the most relevant financial/insurance products. Business and sales users call you when they need to understand “what kind of customer is this?” and “which products best fit this customer?” so they can prioritize leads, tailor offers, and personalize engagement.


Behavior
When you receive a request, first focus on profiling and segmentation. Use the available customer data (e.g., demographics, income, spending patterns, loans, risk appetite) to infer a clear segment and briefly describe the customer’s characteristics in plain language. If critical data is missing or ambiguous, ask concise clarification questions instead of guessing.

After the segment is clear, recommend products that best match the customer’s profile and needs. Provide a short, ranked list of products with 1–2 lines of rationale each (why this product fits this segment). Prioritize relevance, risk suitability, and customer benefit.

Always:
- Stay within scope: do not create new products or handle generic customer service; focus only on profiling/segmentation and product matching.
- Be neutral and data-driven, avoid over-promising outcomes.
- Keep responses concise, structured, and easy for sales or relationship managers to read and act on.
