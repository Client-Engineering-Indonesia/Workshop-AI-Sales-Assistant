# MCP connector using Tavily connector 

### Introduction
MCP is a standard that allows agents to securely and flexibly interact with external tools and data sources through MCP servers. MCP enables agents to discover, connect to, and start external tools that are provided by MCP servers. These servers function as intermediaries, presenting various capabilities (such as searching the web, querying a database, sending email, or fetching web content) in a standardized manner. This process does not require creating custom APIs or manually setting up connections, making it a simpler and more efficient method for agents to use external tools.

With MCP, agents can discover and use these external tools during run time, enhancing their capabilities beyond their inherent features. All interactions with external tools are managed through a single protocol, which simplifies connections and improves efficiency. Moreover, MCP facilitates collaboration and tool sharing among agents from different vendors or platforms. 

During this lab you will learn how to add a Tavily web search tool to an agent, imported using an MCP server provided by Tavily. If you want to try MCP server with Langflow go [here]([Lab 1 - Build RAG tools using Langflow and watsonx Discovery](https://github.com/Client-Engineering-Indonesia/Incubation-Agentic-AI-2025-batch-2/tree/main/Lab%201%20-%20Build%20RAG%20tools%20using%20Langflow%20and%20watsonx%20Discovery)). Tavily is a search engine and API specifically designed for AI agents and Retrieval-Augmented Generation (RAG) workflows. It provides real-time, accurate, and factual search results tailored for use with large language models (LLMs). Unlike traditional search engines, Tavily focuses on providing concise, ready-to-use information optimized for LLM context, streamlining the process of integrating
dynamic web information into AI-driven solutions.

# MCP connector in watsonx orchestrate 



To install MCP servers that require environment variables, you must add the required variables into an AppID/Connection using key-value pairs. MCP servers fetch the environment variables when they start, so it is important to set the variables before you import or start an MCP server.

To connect to the Tavily server with your credentials, you must create a new connection in watsonx orchestrate. This is the most secured way to import tools not displaying your API keys and credentials publicly.

Return to your watsonx Orchestrate top menu. 
1. Click the Main menu icon (A)
2. Expand the Manage menu (A) then select Connections (B)
3. Click Add new connection (A).
4. Enter Tavily_MCP in the Connection ID* field (A), click Save and continue (B).
5. Expand the Choose an option in the  Authentication type menu (A). 
6. Select Key Value Pair (A).
7. Type TAVILY_API_KEY in the Key name field (A),  copy your Tavily API key from your note in the 
Value field (B), Click Connect (C).
8. Check that your draft connection is Connected (A), Click Next (B).
9. Repeat from Step 5 and add the credentials for the Live environment. 
10. Click Add connection (A) when done.
11. Check that your  connection is now ready (A), both draft and live environments will have access to 
your credentials in a secured way. Click the top menu (B).
