# Introduction to watsonx BI

watsonx BI is IBM’s new AI-native business intelligence tool that lets you ask questions about your data in natural language and get back charts, tables, and insights automatically.<br>

By the end of this lab you will be able to:<br>
- Connect a dataset (or DB table) to **watsonx BI**
- Build a simple **semantic model** (dimensions, measures, and business-friendly names)
- Ask **natural language questions** over the data and visualize the results
- Create a basic **dashboard** that tracks key sales KPIs (leads, conversion, premium/AUM, etc.)
- Understand how watsonx BI can complement your **agentic Sales Assistant** from earlier labs
